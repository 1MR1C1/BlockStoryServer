# Block Story Server

Host your own Block Story world for friends, from a desktop app. Pick a world, press Start, play.

It runs the server that comes with the game itself, so nothing extra gets installed into Block Story and the server always matches your game version.

## Download

Go to the [Releases](../../releases) page and grab `BlockStoryServer-Linux`. It's self-contained, nothing else to install. Make it executable and run it.

Linux only for now. The game's server part only ships in the Linux version of Block Story.

## What it does

- **Worlds** - make new worlds, import ones from the game, switch between them, each with its own settings.
- **Start / stop / restart** - the world saves by itself when the server stops. Save any time with one button.
- **Players** - see who's online, whitelist and admin lists.
- **Mods per world** - pick which mods a world uses. Everyone joining gets just those, and you can force mod settings so every player plays by the same rules.
- **Mod store** - browse and add mods from the BSMK store right in the app, and keep them up to date.
- **Backups** - back a world up and roll it back.
- **Friends** - Steam invites so friends can join without port forwarding.
- **Console** - the server's live log.
- **Updates itself** - new versions download and install on their own, the app just asks you to restart.

## Requirements

- Block Story on Linux, installed through Steam and up to date.
- For mods: the BlockStoryCore framework, which the Block Story Mod Kit installs in one click.
